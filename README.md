# Quiz App

A simple and interactive Quiz App built using HTML, CSS, and JavaScript.  
It allows users to answer multiple-choice questions, view their scores, and restart the quiz.

---

## Features
- Displays multiple-choice quiz questions  
- Tracks and displays the user’s score  
- Shows correct answers after submission  
- Option to restart the quiz after finishing  
- Responsive design for all devices  

---

## Technologies Used
- HTML5  
- CSS3  
- JavaScript (ES6)
